# HousingPulse Dashboard

## Description
This project is an earlier version of the HousingPulse dashboard. It analyzes rent and housing price data using Python and Streamlit.

The dashboard uses housing rent data and housing price index data to help compare housing trends across U.S. states.

The final updated version of this project is in the repository called **HousingPulse_Group_Project**.

## Language
Python

## Libraries
Streamlit, pandas, matplotlib

## Files
- app.py: Main Streamlit dashboard code
- FY26_FMRs.xlsx: Rent data
- hpi_po_state.xlsx: Housing Price Index data
- requirements.txt: Required Python libraries
